## Context

当前项目在页面标题、PWA manifest、UI 标题以及包名等位置仍使用旧名称，造成对外展示不一致。此次变更需要在不影响功能与路由的前提下，统一应用的品牌名称为“gipsy”。

## Goals / Non-Goals

**Goals:**
- 将用户可见的应用名称统一为“gipsy”。
- 确保 PWA 安装信息与浏览器标题一致。
- 更新包名，保持项目元信息一致性。

**Non-Goals:**
- 不变更 Garfish 集成逻辑与子应用管理行为。
- 不调整任何路由、功能或 UI 布局。
- 不迁移或重置本地存储数据。

## Decisions

- 只替换对外可见的名称字段（页面标题、manifest、首页标题、包名），避免影响运行时逻辑与存储键。
  - 备选方案：同时替换所有与“garfish”相关的内部标识。未选用原因：会影响兼容性与历史数据，并可能引发不必要的行为差异。

## Risks / Trade-offs

- [Risk] 用户可能仍在浏览器缓存中看到旧的 PWA 名称 → [Mitigation] 更新后版本提示刷新，PWA 更新后名称自动生效。
- [Risk] 包名变更可能影响 CI 或发布脚本的读取 → [Mitigation] 在任务中明确需要检查相关脚本或文档。

## Migration Plan

- 修改配置与文案后重新构建发布即可生效。
- 如需回滚，仅需将相关名称字段改回旧值并重新发布。
