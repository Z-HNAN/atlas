# app-management

## 规范目标
- 支持应用配置（name/url）的新增、删除与本地持久化。
- 首页以紧凑、响应式卡片展示应用。

## 功能与行为

### 要求：新增应用
- **当** 用户在 `/settings` 填写 `name` 与 `url` 并提交
- **则** 应用写入本地配置并返回首页

- **当** `name` 或 `url` 为空
- **则** 阻止提交并提示错误

- **当** `url` 不是合法 URL
- **则** 阻止提交并提示错误

### 要求：删除应用
- **当** 用户在首页点击删除按钮
- **则** 弹出确认；确认后从本地配置移除并从列表消失

### 要求：本地持久化
- **当** 门户刷新或重新打开
- **则** 从本地存储恢复应用配置

### 要求：首页卡片（紧凑 + 响应式）
- **当** 首页渲染应用列表
- **则** 使用响应式网格展示卡片，并保持可点击性

- **当** 视口变窄/变宽
- **则** 列数与间距自适应

### 要求：点击卡片启动应用
- **当** 用户点击应用卡片
- **则** 导航到跳转入口（详见 `app-launch` 规范）
